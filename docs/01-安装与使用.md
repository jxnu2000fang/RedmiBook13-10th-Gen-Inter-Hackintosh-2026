# 01 · 安装与使用

> 本文假设你已经有了一台能启动 macOS 的机器（或愿意从 U 盘安装）。如果你是从零开始装系统，请先看 [04-故障排查.md](04-故障排查.md) 的「从零安装」一节。

---

## 第 0 步：备份（不可跳过）

EFI 被错误覆盖且没有备份，机器会直接无法开机，只能拆硬盘或用另一台电脑救。

macOS 下挂载 EFI 分区并整体备份：

```bash
# 1. 找到 EFI 分区（通常是 disk0s1）
diskutil list

# 2. 挂载（本机卷标是 SYSTEM，别的机器可能是 EFI 或 NO NAME）
diskutil mount disk0s1

# 3. 整体复制一份到桌面（把 /Volumes/SYSTEM 换成你实际的挂载点）
ditto /Volumes/SYSTEM/EFI ~/Desktop/EFI-备份-$(date +%Y%m%d)
```

也可以直接用 [Hackintool](https://github.com/headkaze/Hackintool) 的「磁盘 → 挂载 EFI」按钮，图形化操作。

> **小坑：** 本机的 EFI 分区卷标是 `SYSTEM`，不是网上教程里常见的 `EFI`。挂载后如果 `/Volumes/EFI` 不存在，去 `/Volumes/` 下面看一眼实际名字。挂载 EFI 分区需要管理员权限，报 `kDAReturnNotPermitted` 时用 `sudo diskutil mount disk0s1`。

## 第 1 步：生成你自己的三码

**这一步不做，系统能开机但 App Store / iCloud / iMessage 全部不可用。**

本仓库的 `config.plist` 中以下四个字段已被清空：

| 位置 | 字段 |
|------|------|
| `PlatformInfo > Generic` | `SystemSerialNumber`、`MLB`、`SystemUUID`、`ROM` |
| `PlatformInfo > DataHub` | `SystemSerialNumber`、`SystemUUID` |
| `PlatformInfo > SMBIOS` | `SystemSerialNumber`、`SystemUUID`、`BoardSerialNumber`、`ChassisSerialNumber` |

生成与填写方法见 **[02-生成三码.md](02-生成三码.md)**。

---

## 第 2 步：替换 EFI

有两种方式，任选其一。

### 方式 A：手动替换（推荐，可控）

```bash
# 挂载 EFI 分区
sudo diskutil mount disk0s1

# 只替换 BOOT 和 OC 两个目录，其余（如 Microsoft）保持不动
sudo rm -rf /Volumes/SYSTEM/EFI/BOOT
sudo rm -rf /Volumes/SYSTEM/EFI/OC
sudo cp -R ~/Downloads/redmibook13-monterey-opencore/EFI/BOOT /Volumes/SYSTEM/EFI/
sudo cp -R ~/Downloads/redmibook13-monterey-opencore/EFI/OC   /Volumes/SYSTEM/EFI/
```

### 方式 B：Hackintool 拖拽

挂载 EFI 后，在 Finder 里把本仓库的 `EFI/OC` 整个拖进 `/Volumes/SYSTEM/EFI/`，覆盖同名目录。系统会要求输入密码。

**不要**把 `EFI/Microsoft`（Windows 引导）删掉，否则 Windows 会进不去。

## 第 3 步：首次启动

1. 重启，按住 `Esc` 或 `F12` 进启动菜单，选择 `OpenCore`（或 `EFI Boot`）。
2. 进入 OpenCore 图形菜单后，先选 **`Reset NVRAM`** 回车，机器会自动重启一次。
   - 这一步会清掉旧的启动参数缓存。如果之前注入过别的 `boot-args`，不清会带着旧参数启动。
3. 再次进入菜单，选 macOS 启动。

首次启动比平时慢，且可能黑屏几秒（显卡 framebuffer 初始化），属正常现象，**不要急着强制关机**。

## 第 4 步：验证是否生效

进入系统后逐项确认：

| 检查项 | 命令 / 位置 | 期望结果 |
|--------|-------------|----------|
| 三码已生效 | `system_profiler SPHardwareDataType` | 显示你自己生成的序列号，**不是**空，也不是别人的 |
| 机型 | 同上 | `MacBook Pro (16-inch, 2019)` / `MacBookPro16,4` |
| 核显 | `system_profiler SPDisplaysDataType` | `Intel UHD Graphics 630`，VRAM 2048 MB，Metal 支持 |
| 扬声器 | 系统设置 → 声音 → 输出 | 有「内置扬声器」，播放音频有声 |
| **耳机** | 插上耳机，再看 系统设置 → 声音 → 输出 | 出现 `Headphones` 并自动切换，耳机有声 |
| 麦克风 | 同上 → 输入 | 有「内置麦克风」，输入电平条有反应 |
| 电池 | 菜单栏电池图标 | 显示百分比，不是叉 |
| 亮度 | 键盘 F1 / F2 | 能调亮度 |
| Wi-Fi | 系统设置 → 网络 | 能看到 Wi-Fi 接口并能连上 |
| 启动参数 | `nvram boot-args` | 与 config 中一致 |

**耳机这一项是本包的重点。** 如果插上耳机没有 `Headphones` 设备、仍然是外放，看 [04-故障排查.md](04-故障排查.md) 第 3 节。

其余项目不符，同样看第 04 篇。

## 第 5 步：稳定后的小优化（可选）

`config.plist` 里的 `boot-args` 目前是：

```
ps2kbonly=1 darkwake=0 alcdelay=500 alctsel=1 alcverbs=1 -wegnoegpu debug=0x100 keepsyms=1
```

- `debug=0x100 keepsyms=1` 是排错用的**调试开关**，会让启动变慢、日志变多。确认系统稳定后可以删掉这两个，启动会快一些。
- `alcdelay=500 alctsel=1 alcverbs=1` 是 AppleALC 的时序调优，**不要删**，删了可能没声音或耳机检测失灵。
- `-wegnoegpu` 禁用独显，本机没有独显，保留无害。
- `ps2kbonly=1` 表示只用 PS/2 键盘驱动，如果你的键盘是 I2C 的需要调整。

修改后记得回来 `Reset NVRAM` 一次，否则旧值还在缓存里。

---

## 关于 SIP

本配置的 `csr-active-config = 0x03E7`，即 **SIP 已关闭**。

关闭 SIP 是为了让 `VoltageShift` 等工具能工作。代价是系统完整性保护失效，安装来路不明的 kext 或脚本会更危险。

想恢复默认 SIP，把 `NVRAM > Add > 7C436110-... > csr-active-config` 改成 `00000000` 数据，重启后 `csrutil status` 应显示 `enabled`。注意部分驱动在 SIP 开启后会失效。

---

## 回滚

出问题时：

1. 重启进 OpenCore 菜单 → 选 `Reset NVRAM`；
2. 如果还是不行，用另一台电脑（或 macOS 恢复模式）挂载 EFI 分区，把第 0 步的备份整个拖回去；
3. 最坏情况下，拆下硬盘接到另一台电脑上还原 EFI 备份。

**只要第 0 步的备份还在，就没有救不回来的情况。**
